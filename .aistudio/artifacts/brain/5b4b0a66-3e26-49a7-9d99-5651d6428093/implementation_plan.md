# Проект 25: Блок «Дело #3: Кто на фото?» (Парные фото: _crop и оригинал)

Обновлённый план реализации третьего дела квеста с пошаговым прохождением 6 архивных фото, где для каждого снимка используются загруженные вами парные файлы из папки `blok3`:
- **Фрагмент-загадка:** `kto1_crop.PNG` ... `kto6_crop.PNG`
- **Полная разгадка:** `kto1.PNG` ... `kto6.PNG`

---

### Вопросы для финального согласования:
1. **Вопросы и варианты ответов:**
   Хотите ли вы сами прислать правильные ответы для каждого из 6 фото по очереди (как мы делали в Уликах 1-5 Блока 1), а я предложу смешные детективные варианты?
2. **Анимация перехода:**
   При нажатии на «Раскрыть полное фото» делаем плавный переход («проявление» через растворение / «раздвигающаяся диафрагма объектива» камеры) с показом праздничных конфетти и юмористического пояснения.

## 1. Overview & Core Concept

1. **Пошаговое прохождение (6 улик):**
   - Дашуля видит экран **«Дело 3 из 4: Кто на фото?»**.
   - Вверху расположена полоса прогресса: 6 бейджей архивных дел (Улика 1...6).
2. **Начальный показ загадки:**
   - Показывается ваш кропленный файл (`ktoX_crop.PNG`) в стильной рамке с метками «Секретный фрагмент архива».
   - Дашуля отвечает на вопрос: «Кто запечатлён на этом архивном кадре?».
3. **Ответ и кнопка раскрытия:**
   - При неверном ответе — мягкая подсказка с возможностью попробовать снова.
   - При верном ответе — победная неоновая подсветка, аудио-эффект успеха и разблокировка кнопки **«Раскрыть полное фото 🔍»**.
4. **Трансформация в полную версию:**
   - По клику на кнопку запускается кинематографичная анимация: фрагмент плавно раскрывается в полный снимок (`ktoX.PNG`), открывая всю забавную ситуацию целиком!
   - Появляется авторский комментарий / разгадка.
5. **Переход к следующему фото:**
   - Кнопка **«Следующая улика ➔»** переводит к следующему снимку.
   - После завершения 6-го фото Дашуля получает третью цифру секретного кода (`0`) и торжественный переход к следующему делу!

## 2. User Experience & Visual Design

- **Детективная карточка улики:**
  - Тёмная неоновая карточка в стилистике «Архив спецотдела 25».
  - Превью кропа с плашкой «Секретный фрагмент» и водяным знаком расследования.
  - Полноэкранный просмотр фрагмента и полного фото по клику на лупу.
- **Интерактивные кнопки выбора:**
  - 4 варианта ответа с мягкими анимациями наведения, детективными буквами (`A`, `B`, `C`, `D`).
- **Эффект раскрытия фото:**
  - Плавный кроссфейд (`opacity transition` + лёгкий `scale`) между `ktoX_crop` и `ktoX` с эффектом «фокусировки объектива».
  - Золотые искры и надпись «Личность идентифицирована!».
- **Graceful Fallback:**
  - Если файл оригинального полного фото ещё загружается или временно отсутствует, компонент элегантно показывает увеличенный кроп с аккуратной заглушкой без поломки вёрстки.

## 3. Key Product Decisions & Trade-Offs

- **Прямая привязка файлов по схеме `ktoX_crop` ➔ `ktoX`:**
  - *Плюс:* Максимальная простота для автора. Вам не нужно вручную подбирать CSS-проценты или координаты — вы сами в фоторедакторе вырезали именно ту область, которую посчитали нужной.
  - *Отказоустойчивость:* Встроенный загрузчик пробует форматы `.PNG`, `.png`, `.jpg`, `.jpeg`, чтобы не зависеть от регистра букв в имени файла.
- **Относительные пути для GitHub Pages:**
  - Все пути к фото задаются через `./blok3/...` и лежат в `public/blok3/`, что гарантирует 100% работоспособность при экспорте и деплое на GitHub Pages.
- **Управление через единый `CONFIG` в `index.html`:**
  - Блок полностью настраивается через массив `CONFIG.whoIsOnPhotoArchive`:
    ```javascript
    whoIsOnPhotoArchive: [
      {
        id: 1,
        cropPhoto: './blok3/kto1_crop.PNG',
        fullPhoto: './blok3/kto1.PNG',
        question: "Кто запечатлён на этом секретном снимке?",
        options: [
          { text: "Правильный ответ...", correct: true, comment: "Идеально раскрыто!" },
          { text: "Смешной вариант...", correct: false },
          { text: "Детективный вариант...", correct: false },
          { text: "Неожиданный вариант...", correct: false }
        ]
      },
      ...
    ]
    ```

## 5. Step-by-Step Implementation Sequence

1. **Синхронизация ассетов:**
   - Обеспечить наличие `public/blok3/` со всеми `kto1_crop.PNG` ... `kto6_crop.PNG` и шаблонами полных фото.
2. **Обновление структуры данных `CONFIG` в `index.html`:**
   - Заменить заготовку `CONFIG.whoIsOnPhotoArchive` на 6 полноценных объектов с парами `cropPhoto` / `fullPhoto`.
3. **Реализация UI Экрана 3 («Дело #3: Кто на фото?»):**
   - Блок фотокарточки с переключением `isRevealed`.
   - Кнопка «Раскрыть полное фото» с анимацией и конфетти.
   - Пошаговый переход от 1-й к 6-й улике.
   - Подсчёт прогресса и выдача 3-й цифры кода `0`.
4. **Безопасная обработка изображений:**
   - Fallback `onerror`, чтобы при отсутствии полного фото приложение показывало фрагмент без сбоев.
5. **Сборка и проверка:**
   - Запуск `compile_applet` и тестирование всех переходов.
